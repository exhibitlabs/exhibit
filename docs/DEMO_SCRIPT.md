## Re-recording

The sandbox filing in this cut is real. Re-shooting the approval files again on PP-R-EGO-10193744, so only do it on purpose.

1. Sandbox (`:3100`), read-only shots: `REC_OUT=/tmp/v5rec node sandbox5.js s5-open s5-refund s5-cite s5-ask`. `s5-ask` spends one Claude CLI answer.
2. Sandbox investigation: `ALLOW_RUN=1 node sandbox5.js s5-run`. It re-runs the agent (reads only, about 35 s of Claude) and replaces the case's latest brief.
3. Agent request: `EXHIBIT_URL=http://localhost:3100 DEMO_PROMPT="…" node mcp/agent-demo.ts`. It overwrites `docs/MCP_DEMO.md`; restore the committed run with `git checkout docs/MCP_DEMO.md`. The v5 transcript is kept in the video project at `notes/mcp-sandbox-run.md`.
4. Approval, the one write: `ALLOW_APPROVE=1 node sandbox5.js s5-approve`. It refuses unless exactly one pending request exists on the case and that request is pinned to the latest brief.
5. Demo merchant (`:3101`): `curl -X POST localhost:3101/api/demo -H 'Content-Type: application/json' -d '{"op":"reset"}'`, then `node demo5.js d5-prevent`.
6. `python3 tools/build_v5.py`, `npx hyperframes check`, then `npx hyperframes render --quality delivery --frames-cache-dir off`. The render's voice track sits at about −19 LUFS. Normalize it with a two-pass ffmpeg `loudnorm` (I=−16, TP=−1.5, linear) and `-c:v copy`.
